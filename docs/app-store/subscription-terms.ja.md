# 自動更新の表示原稿

購入画面では、プラン名、期間、期間全体の税込価格を購入前に表示します。価格は StoreKit が返す地域別の表示価格を使います。年額を表示する際は、月額換算より年額の請求額を優先します。利用規約とプライバシーポリシーは同じ画面から開けます。App Store Connect にはプライバシーポリシー URL を登録し、説明文末尾に Apple の標準使用許諾契約へのリンクを掲載します。[App Review 3.1.2](https://developer.apple.com/app-store/review/guidelines/#subscriptions) · [自動更新サブスクリプション](https://developer.apple.com/app-store/subscriptions/)

## 掲載用

ふたりの家計簿 Pro は、日本では月額480円（1か月）または年額3,600円（1年）の自動更新プランです。1契約で共有家計簿のふたりとも利用できます。対象の方は年額を14日間無料で試せます。無料体験の終了後は、解約しない限り、購入画面に表示された年額料金が請求されます。

購入の確定時に Apple Account に請求されます。現在の期間が終了する24時間前までに自動更新を停止しない限り、契約は次の期間に更新されます。更新料金は期間終了前の24時間以内に請求されます。無料体験の後に課金されたくない場合は、体験終了の24時間前までに解約してください。

契約の確認・解約は、端末の「設定」→自分の名前→「サブスクリプション」から行えます。アプリを削除しても契約は解約されません。[解約手順](https://support.apple.com/ja-jp/118428)

公開時は登録したプライバシーポリシー、利用規約、Apple 標準使用許諾契約のリンクが開くことを確認します。[Apple標準使用許諾契約](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)
