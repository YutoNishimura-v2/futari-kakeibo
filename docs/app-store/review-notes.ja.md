# App Review メモ

iOS / iPadOS 17 以降に対応しています。アプリ専用アカウントの登録は不要です。無料で支出記録、月ごとの精算、iCloud 共有を確認できます。

## 2つの Apple Account で共有を確認

1. iCloud に別々の Apple Account でサインインした端末 A・B に審査対象ビルドを入れます。
2. A で「支出を記録」から任意の支出を保存します。ホーム右上の「ふたりと共有」→「パートナーを招待」で、B の Apple Account のメールアドレスを入力して招待リンクを作り、B に送ります。
3. B でリンクを開き、招待を承諾します。共有の家計簿が開き、A の支出が表示されます。B でも支出を保存し、同期後に A の「今月の精算額」から開く月の明細で、B の支出と精算額を確認できます。

## StoreKit サンドボックスで Pro を確認

1. 審査環境のサンドボックスで購入します。開発者側で再現する場合は TestFlight、または Xcode の StoreKit Configuration を「None」にした署名済み開発ビルドと Sandbox Apple Account を使います。
2. A で「ふたりと共有」→「定期入力」の鍵、または「家計簿を追加」の鍵をタップします。「ふたりの家計簿 Pro」で月額・年額・買い切りの選択肢と価格が出ます。年額の無料体験は、同じ購読グループの体験資格があるアカウントで確認できます。
3. A で購入を完了し、「定期入力」を開けることを確認します。B は購入せず、同じ共有家計簿を開き直して同期を待ち、「定期入力」を開けることを確認します。B 自身の家計簿に切り替えると、B が未購入であれば Pro は有効になりません。共有による反映を検証する場合、A・B は Apple のファミリー共有に入っていないアカウントを使います。
4. 購入した同じアカウントでアプリを入れ直し、「ふたりと共有」→「Proプラン・購入の復元」から「購入を復元」を押します。家計簿の取り込みと購入の確認後に Pro が使えます。各プランを初回購入として試す場合は、サンドボックスの購入履歴を消すか、新しい Sandbox Apple Account を使います。

購入画面とホーム右上の「ふたりと共有」の末尾から、利用規約とプライバシーポリシーを開けます。
