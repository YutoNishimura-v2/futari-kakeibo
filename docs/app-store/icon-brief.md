# アプリアイコン制作要件

見開きの帳面を、背でつながった二つの面として描く。両ページに1本ずつ短い罫線を置き、同じ高さで揃えて「ふたりで付ける家計簿」を表す。背景は生成り、面は深い緑の平塗りを第一候補とし、単色でも帳面の輪郭が読める太さにする。文字、通貨記号、ハート、グラデーション、発光、影は入れない。

1024 × 1024 px の不透明な正方形を用意する。角丸は iOS に任せる。ホーム画面相当の60 pxと小さい通知相当のサイズに縮め、罫線が潰れず隣のアプリと見分けられるか確認する。候補はホーム画面上の実寸比較で見せ、採用後に Xcode の AppIcon アセットへ登録する。[Appleのアイコン指針](https://developer.apple.com/design/human-interface-guidelines/app-icons)
