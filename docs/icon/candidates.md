# ふたり家計簿のアイコン候補

おすすめは A。見開きだけで、ふたりで付ける家計簿だと伝わります。

| A | B | C |
|---|---|---|
| ![見開きの帳面](candidates/a.svg) | ![重なる硬貨](candidates/b.svg) | ![共用の財布](candidates/c.svg) |

- **A　見開きの帳面**　`#F4EAD6` `#174938`。左右に同じ罫線を置き、ふたりが一冊に記録することを表します。
- **B　重なる硬貨**　`#7C3127` `#EDAB56` `#FFF0CD`。二枚の硬貨を重ね、ふたりがお金を持ち寄ることを表します。
- **C　共用の財布**　`#EBE6F7` `#7255AA` `#38245E`。二色の面を一つの留め具でまとめ、生活費を一緒に管理することを表します。

日本の App Store では、シェアルーは多色の円グラフ、OsidOri は白地に緑の線画、ペアカードのワンバンクは暖色に白い斜線が目印です。A は生成り地と帳面の左右対称、B は赤茶の地と二枚の硬貨、C は紫と横長の財布で見分けられます。 [シェアルー](https://apps.apple.com/jp/app/id1475406336)・[OsidOri](https://apps.apple.com/jp/app/id1473751623)・[ワンバンク](https://apps.apple.com/jp/app/id1487752024)
